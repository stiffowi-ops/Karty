# Карта локаций: Telegram-бот без Mini App · версия 2.0

Полностью обычный Telegram-бот на **Go 1.23**: никаких сайтов, доменов, HTTPS, Caddy и открытых портов. Используется `getUpdates` (long polling). Исходники можно положить в GitHub, **секретный `.env` хранить только на VPS**.

## Что умеет

- `/start` — меню с кнопками «Рядом со мной», «Список станций», «Поиск», «Общая карта».
- Поиск по русским названиям (например, «Троицк», «Королёв»), в том числе с `ё/е`.
- Каталог из **40 локаций**, названия уже входят в репозиторий.
- Отправка изображения станции в чат Telegram (после загрузки PNG с публичного Яндекс Диска) и подпись с описанием и оценкой. Оценки **не выдуманы**: их задаёт администратор в конфигурации.
- По нажатию **«📍 Рядом со мной»** Telegram спрашивает разрешение отправить одну геопозицию. Бот находит **до 5 ближайших объектов с известными координатами** и показывает расстояния **по прямой**, кнопки карточек.
- Можно также отправить боту точку из меню вложений Telegram.
- Кнопка «Общая карта» открывает исходный конструктор Яндекс Карт. У станции с координатами появляется кнопка перехода непосредственно к её точке.
- Автоматическая проверка изображений в публичной папке Яндекс Диска каждые 12 часов и при старте. Команда `/sync` для администратора. При ошибке обновления ранее загруженные карточки остаются.
- `/status` — число объектов, скачанных PNG, объектов с координатами и оценками; `/reload` — перечитать конфигурацию без перезапуска; `/id` — узнать Telegram ID.

**Важное ограничение.** Исходный конструктор Яндекса по публичной ссылке не отдаёт доступные проекту координаты меток. В `config/seed.json` есть только названия. Для реальной работы поиска ближайших локаций нужно заполнить **широту и долготу** этих объектов в `config/overrides.json`, желательно по экспорту карты. Поскольку часть станций существует только как проект, автоматически искать их координаты как действующие станции метро небезопасно.

В проекте **нет самих 40 PNG-файлов**: они скачиваются с публичного Диска только при работающем серверном доступе. Если API Диска временно недоступен, бот покажет карточку текстом, а не выдуманную картинку.

## 1. Положи файлы в GitHub

Создай пустой репозиторий GitHub, загрузи содержимое папки `location-bot/`:

```bash
git init
git add .
git commit -m "Telegram location bot v2"
git branch -M main
git remote add origin https://github.com/YOUR_USER/location-bot.git
git push -u origin main
```

Не добавляй `.env` в репозиторий: он исключён в `.gitignore`. Координаты и описания в `config/overrides.json` допустимо хранить в GitHub, если данные публичные. Файлы из `runtime/` и кэш изображений не хранятся в Git.

## 2. Подними на сервере Ubuntu или Debian

Нужны Docker Engine + плагин Docker Compose, а также сетевой доступ к `api.telegram.org`, `cloud-api.yandex.net` и доменам Яндекс Диска. Домен **не нужен**, открывать входящие порты **не нужно**.

```bash
sudo mkdir -p /opt/location-bot
sudo chown "$USER":"$USER" /opt/location-bot
cd /opt/location-bot
git clone https://github.com/YOUR_USER/location-bot.git .
cp .env.example .env
nano .env
```

Обязательно укажи реальный токен из [@BotFather](https://t.me/BotFather):

```dotenv
BOT_TOKEN=123456:YOUR_REAL_BOT_TOKEN
ADMIN_IDS=123456789
```

`ADMIN_IDS` можно временно оставить пустым. Запусти бота, отправь ему `/id`, внеси свой ID в `.env` и затем сделай `docker compose up -d` с пересозданием контейнера.

```bash
chmod 600 .env
docker compose up -d --build
docker compose logs -f --tail=100 bot
```

Бот начнёт принимать `/start`. Администратор может выполнить `/sync` (принудительно синхронизировать изображения) и `/status` (проверить наличие загруженных карточек).

## 3. Как добавить координаты, оценки и описание

В `config/overrides.example.json` подготовлены **все 40 идентификаторов** с пустыми значениями. Перенеси нужные объекты в `config/overrides.json` и заполни их проверенными данными. Например:

```json
{
  "017": {
    "description": "Описание локации, которое увидит пользователь",
    "rating": "8/10",
    "lat": null,
    "lon": null
  }
}
```

`lat` — широта от −90 до 90, `lon` — долгота от −180 до 180. `null` означает **координат нет**, поэтому станция не участвует в расчёте ближайших. Вместо `null` установи конкретные проверенные числа из карты. Рейтинг можно оставить пустым, тогда он не показывается. Другие поля: `title`, `category`.

После изменения `config/overrides.json` отправь боту в **Telegram** команды `/reload` (перечитать конфигурацию) и `/status` (проверить результат). Эти команды не вводятся в терминал. Если правишь файл на сервере и Git сообщает о локальных изменениях при `git pull`, лучше управлять `overrides.json` через GitHub или отдельно продумать хранение изменяемого каталога.

**Принцип работы геопоиска:** пользователь добровольно отправляет координаты → бот рассчитывает расстояния по сфере (формула гаверсинусов) → сортирует только объекты с проверенными координатами → возвращает до 5 ближайших. Это не расстояние пешком и не расчёт маршрута метро. Геопозиции не сохраняются на сервере в файлы/базу; в Telegram отправленные пользователем сообщения с геопозицией остаются в истории чата согласно настройкам Telegram.

## 4. Обновление через GitHub

```bash
cd /opt/location-bot
git pull --ff-only
docker compose up -d --build
```

`.env` и скачанные изображения в Docker volume сохраняются. Если меняешь `overrides.json`, бот прочитает новые данные по `/reload` или при перезапуске.

## Проверка Go без Telegram

Если на компьютере Go 1.23+:

```bash
go test ./...
go build ./...
```

Для реальной проверки Telegram нужен действительный токен и доступ к сервису Telegram. Реальная загрузка PNG с Яндекс Диска также зависит от доступности API именно с твоего сервера.

## Структура проекта

```text
location-bot/
├── main.go
├── internal/
│   ├── telegram/       # команды, поиск, запрос геопозиции, фото
│   ├── catalog/        # каталог, оценки, описания, координаты
│   └── syncer/         # импорт PNG через API Яндекс Диска
├── config/
│   ├── seed.json               # 40 названий
│   ├── overrides.json          # реальные настройки (пустые по умолчанию)
│   └── overrides.example.json  # шаблон для 40 локаций
├── docker-compose.yml
├── Dockerfile
├── .env.example
└── README.md
```
